# Startpagina

De startpagina van **https://startdagen.peno1.be**, in KU Leuven-huisstijl
(kleuren en logo uit het officiële logo-SVG). Voorlopig staat er enkel het
Wiskunde-onderdeel (`/wiskunde/`); nieuwe onderdelen voeg je toe door in
[index.html](index.html) een extra kaart (`<a class="card" ...>`) naast die
van Wiskunde te zetten.

Deze map bevat enkel de statische inhoud. De pagina wordt geserveerd door
de gecombineerde app in [../wsgi.py](../wsgi.py); zie
[../DEPLOY.md](../DEPLOY.md) voor het deployen.
