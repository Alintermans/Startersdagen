Ingebouwd ledje

Led staat voor Light Emitting Diode: een halfgeleider die licht uitzendt zodra er stroom door vloeit. Elke Arduino heeft een ingebouwd ledje dat intern verbonden is met pin 13. In de Arduino-code heet die pin LED_BUILTIN. Zet je die pin hoog (HIGH), dan brandt het ledje; zet je hem laag (LOW), dan dooft het.

Open de Arduino IDE. Download dit bestand, open het (eventueel ga je de code moeten kopiëren naar een nieuw Arduino-bestand) en upload vervolgens deze code naar de Arduino. Vergeet niet om bij 'Select Board' de juiste Arduino te selecteren, anders is het niet mogelijk om je code te uploaden. Het ledje op het bordje (aangeduid met een L, naast de TX- en RX-ledjes) zou nu één keer per seconde moeten knipperen.

Opdracht 2.1

Laat het ledje twee keer zo snel knipperen door de wachttijden in dit stuk code aan te passen. Upload je code opnieuw naar de Arduino en controleer het resultaat. 


void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // ledje aan
  delay(1000);                      // wacht 1000 milliseconden
  digitalWrite(LED_BUILTIN, LOW);   // ledje uit
  delay(1000);
}

Opdracht 2.2

Laat het ledje kort aan en lang uit gaan: 100 milliseconden aan, 900 milliseconden uit.

Opdracht 2.3

Maak een eigen patroon, bijvoorbeeld drie korte flitsen gevolgd door een lange pauze. Tip: je mag in loop() zoveel regels toevoegen als je wil.
