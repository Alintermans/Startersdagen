Opdracht 4.4

Pas de code verder aan zodat de servomotor beweegt aan de helft van de snelheid. 

              
void loop() {
  if (Serial.available() > 0) {
    char letter = Serial.read();
    if (letter == 's') {
      Serial.println("Servomotor begint nu");
      for (i=90; i<=120; i++) {
        myservo.write(i);
        delay(20);
      }
      delay(200);
      for (i=120; i>=90; i--) {
        myservo.write(i);
        delay(20);
      }
    }
  }
}

Opdracht 4.5

Download dit bestand. Team Energie heeft een opstelling waarmee zij met hun batterij een pico microcontroller kunnen voeden. Deze pico is verbonden met een OLED scherm en een buzzer. De pico communiceert nu via UART (digitale communicatie) met de functie sendLetterToPico(). Elke letter vertegenwoordigt één van de 12 professoren, en op de pico is al een vaste mapping geprogrammeerd van elke professor naar een specifiek liedje (de letters a, f en j worden niet meer gebruikt):

b=Van-hamme, c=Smets, d=Vansteenwegen, e=Dehaene, g=Beernaert, h=De-Laet, i=Rijmen, k=Van-Puyvelde, l=Vander-Sloten, m=Geraedts, n=Everaerts, o=Swolfs

Je kan de verschillende professoren en hun bijhorende liedjes testen door een letter uit de lijst te versturen via de Serial Monitor. Wanneer je een letter verstuurt, zal de pico automatisch het liedje van de corresponderende professor afspelen en diens naam tonen op het OLED scherm.

Deze letter-naar-professor mapping zal je moeten onthouden voor de volgende opdracht, waarbij je de juiste letters gaat moeten koppelen aan de juiste kleurencombinaties in de functie stuur_servo().
